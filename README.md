# Simple Interest Calculator

A simple calculator to calculate simple interest using the principal amount, annual rate of interest, and time period.

## Description

This project contains a Bash script named `simple-interest.sh` that calculates simple interest based on user input.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- `p`: Principal amount
- `r`: Annual rate of interest
- `t`: Time period in years

## Usage

Run the `simple-interest.sh` script and enter the principal amount, rate of interest, and time period when prompted.
